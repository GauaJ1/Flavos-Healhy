🛡️ Flavos Healthy — Política de Privacidade de Dados de Saúde

O Flavos Healthy utiliza o Google Health Connect para sincronizar dados nutricionais com aplicativos de saúde instalados no seu dispositivo (como o Samsung Health).

Quais dados são escritos?

  • Dados Nutricionais (NutritionRecord) — calorias, proteínas, carboidratos, gorduras, nome da refeição e tipo de refeição (café da manhã, almoço, jantar, lanche).
  • Hidratação (HydrationRecord) — volume de água ingerida em mililitros.
  • Peso Corporal (WeightRecord) — peso em quilogramas.

Quais dados são lidos?

  • Dados Nutricionais (NutritionRecord) — para exibir histórico de refeições previamente sincronizadas.
  • Peso Corporal (WeightRecord) — para acompanhamento de progresso (funcionalidade futura).
  • Passos (StepsRecord) — para cálculo de gasto calórico (funcionalidade futura).

Como os dados são usados?

  • Os dados de saúde são usados exclusivamente para sincronização bidirecional com o Health Connect.
  • Nenhum dado de saúde é enviado a servidores externos, vendido ou compartilhado com terceiros.
  • Os dados permanecem no seu dispositivo e no ecossistema Health Connect.
  • A análise nutricional (via IA) é processada sem transmitir dados de saúde do Health Connect.

Controle do usuário

  • A sincronização é opcional e desativada por padrão.
  • O usuário pode ativar/desativar a sincronização a qualquer momento no app.
  • As permissões de Health Connect podem ser revogadas a qualquer momento nas configurações do Android.
  • A desinstalação do app remove todos os dados locais.

Segurança

  • Toda comunicação com o Health Connect é feita localmente via APIs oficiais do Android.
  • Nenhuma API key, token ou credencial é armazenada em relação ao Health Connect.
  • Os dados de saúde nunca são logados, enviados por rede ou armazenados em cache permanente.
